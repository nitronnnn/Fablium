# Дотфайлы — Arch Linux + Hyprland

Полный набор конфигов с динамической системой тем: выбираешь **любой цвет из спектра** — палитра генерируется автоматически для всех компонентов.

## Состав

| Компонент | Назначение |
|---|---|
| `hypr/` | Hyprland, hyprlock, hypridle, hyprpaper |
| `waybar/` | Панель |
| `rofi/` | Лаунчер + power-меню |
| `kitty/` | Терминал |
| `dunst/` | Уведомления |
| `scripts/` | Генератор темы и пикеры |

## Установка

```bash
git clone <этот-репозиторий> ~/dotfiles
cd ~/dotfiles
chmod +x install.sh
./install.sh
```

Скрипт установит пакеты через pacman, создаст симлинки в `~/.config` (старые конфиги бэкапятся) и применит тему по умолчанию.

## Система тем

Один базовый цвет порождает всю палитру (фон, поверхности, текст, акценты) для Hyprland, Waybar, Rofi, Kitty и Dunst — и всё перезагружается на лету.

- **`SUPER + T`** — меню тем в rofi: пресеты, ввод своего hex, пипетка
- **`SUPER + SHIFT + T`** — пипетка: кликни в любую точку экрана (открой картинку со спектром и выбери оттуда)
- Вручную: `~/.config/hypr/scripts/theme.sh "#ff8800"`

## Основные хоткеи

| Хоткей | Действие |
|---|---|
| `SUPER + Enter` | Терминал |
| `SUPER + D` | Rofi (приложения) |
| `SUPER + Q` | Закрыть окно |
| `SUPER + F` | Полный экран |
| `SUPER + V` | Плавающее окно |
| `SUPER + L` | Блокировка |
| `SUPER + 1-0` | Рабочие столы |
| `SUPER + SHIFT + V` | История буфера обмена |
| `Print` | Скриншот области |

## Требования

Arch Linux, пакеты ставит `install.sh`: hyprland, waybar, rofi-wayland, kitty, dunst, hyprpicker, grim, slurp и др. Полный список — в `install.sh`.

Обои: положи файл в `~/Pictures/wallpapers/wall.png` (путь настраивается в `hypr/hyprpaper.conf`).
